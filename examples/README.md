# Worked P&ID example

The output of `pid example`, committed so the format is visible without running
anything. Regenerate with:

```bash
pid example --out examples
```

| File | What it is |
|---|---|
| `pid.svg` | The drawing — an oil bleaching unit, 1200-series tags |
| `pid.json` | The model everything else is derived from |
| `findings.txt` | The rule engine's report (this drawing is clean) |
| `equipment_list.csv` | Every tagged item with design conditions and its connections |
| `line_list.csv` | Every line with size, service, spec, endpoints and in-line components |
| `instrument_index.csv` | Every instrument with its ISA function expanded, range and setpoint |
| `loop_schedule.csv` | Each control loop with its valve's fail position joined in |
| `relief_schedule.csv` | Set pressure next to the design pressure it must not exceed |
| `interlock_schedule.csv` | Trips as cause and effect |

The drawing is written by hand in `pid/examples.py` rather than generated by the
agents, so it is stable: the test suite asserts it validates clean and renders
byte-identically. A new rule that fires on it is either a real find or a false
positive worth knowing about.

See [../docs/PID_BUILDER.md](../docs/PID_BUILDER.md) for how the builder works.
